# PushkaraConnect — Project Status

## Project goal
Build a practical pilgrim assistance platform for Godavari Pushkaralu 2027 across Andhra Pradesh and Telangana.

- [ ] Run the web app and API
- [ ] Verify the API health endpoint from the browser

## Important data and safety rules
- This is an independent project, not an official government service.
- Do not publish unverified ghat, bathing, transport, crowd or emergency information as official.
- Store source links and verification timestamps for public information.
- User-submitted crowd reports must be moderated before public display.
- Collect only the personal information needed for a clearly stated purpose.
